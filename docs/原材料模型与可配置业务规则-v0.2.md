# 原材料模型与可配置业务规则 · v0.2

日期：2026-09-09  
公司：潍坊锦安特种设备检测有限公司，山东省安丘市  
依据：用户补充业务说明及《2026年原材料明细表.xlsx》实际工作簿。本文与需求分析 v0.1 配套，冲突时以本次修订为准。

## 1. 本次确定的业务方向

- 公司自有库存以原材料为主；气瓶默认按客户送检、代管、检测、返还流程设计。
- 保留气瓶所有权字段及自有购销扩展能力，但不以公司采购销售气瓶作为首期主流程；相关菜单可关闭。
- 计费方式与报废规则做成后台可配置项，不再要求先确定唯一固定方式才能开发。
- 配置只影响其生效后的业务，历史已过账单据保存规则版本及金额快照。
- 本次仅分析和建模，没有修改源 Excel、导入生产库存或更改服务器。

## 2. 工作簿实际结构

来源为用户指定的微信文件目录下 `2026年原材料明细表.xlsx`。读取工作簿 XML 中的原始值、公式及公式缓存值；未执行 Excel 重算。下述异常均指源文件保存的内容，不把缓存结果当作已核实账目。

工作簿共 12 个工作表：1 个“原材料汇总”及 11 个物料明细页。所有明细页采用 A:L 的收发存账结构。

| 列 | 实际表头 | 模型归属 |
| --- | --- | --- |
| A | 日期 | 单据业务日期；保留原始导入文本 |
| B | 摘要 | 业务摘要，可能混有供应商、用途、颜色或品种 |
| C/D/E | 入库数量 / 单价 / 入库金额 | 入库单明细数量、成交单价、成交金额 |
| F/G/H | 出库数量 / 单价 / 出库金额 | 出库单数量、历史出库计价；不自动解释为对外售价 |
| I/J/K | 库存数量 / 单价 / 库存余额 | 库存余额和成本派生结果，不作为物料档案属性 |
| L | 备注 | 单据或明细备注 |

工作表名称及 A2 标题提供物料名称、部分规格与单位。汇总表 A3:L3 中的“序号”只是展示序号，存在重复，不能用作物料编码。

## 3. 原材料模型属性

以下为逻辑数据模型建议，尚未创建数据库表。业务外键使用 UUID；所有业务表带创建/修改时间及操作人。

### 3.1 物料分类 `material_categories`

- `id`：主键。
- `code`、`name`：分类编码及名称，编码唯一。
- `parent_id`：可选父分类。
- `enabled`、`sort_order`：启停及排序。

初始分类建议为阀门配件、包装耗材、标识耗材、涂装材料、印刷清洗材料，作为可编辑字典。

### 3.2 原材料档案 `materials`

| 属性 | 类型建议 | 规则/来源 |
| --- | --- | --- |
| id / code | UUID / varchar(40) | 系统主键与唯一物料编码 |
| name | varchar(120) | 名称，不把价格拼入名称 |
| category_id | UUID | 分类，可配置 |
| specification | varchar(200) | 10公斤/15公斤/50公斤等业务规格 |
| color | varchar(40)，可空 | 银灰、苹果绿、红色等 |
| model | varchar(100)，可空 | 阀门型号等，未提供时为空 |
| base_unit_id | UUID | 单位字典，业务启用前必填；待清洗档案允许缺失 |
| quantity_scale | smallint | 按单位限制整数/小数，不能统一强制整数 |
| ownership_type | enum | 首期为 company_owned |
| default_purchase_price | numeric(18,4)，可空 | 人工确认后的参考价；缺失不等于0 |
| default_charge_price | numeric(18,4)，可空 | 对客户收费的参考价，与采购成本分开 |
| safety_stock | numeric(18,4)，可空 | 低库存提醒阈值 |
| enabled / data_status | boolean / enum | 待完善、可使用、停用等状态 |
| remark | text | 档案说明 |

名称、规格、颜色和型号用于重复提示，但不以自由文本组合替代唯一编码。不在物料表保存“累计入库/出库/当前库存/已付款”，这些属于动态业务或结算结果。

### 3.3 单位 `units`

- `code`、`name`、`quantity_scale`、`enabled`。
- kg 的显示名称可为公斤，导入别名支持公斤、千克；条、个、张等为不同单位，不自动互换。
- 首期每个 SKU 固定一个基础单位。包装单位换算有明确系数后再启用，系数必须保存在单据快照中。

### 3.4 原材料单据 `material_documents` 与明细 `material_document_lines`

主表：`id`、`document_no`、`business_type`、`business_date`、`warehouse_id`、`partner_id`（可空）、`department_id`、`operator_id`、`status`、`summary`、`remark`、`posted_at`、`reversed_document_id`。

业务类型：采购入库、检测领用、一般领用、退料入库、采购退货、期初、盘盈、盘亏。对外销售作为可选能力，不能将源表出库一律认定为销售。

明细：`material_id`、`location_id`、`quantity numeric(18,4)`、`unit_id`、`unit_price numeric(18,4)`、`amount numeric(18,2)`、`price_basis`、`adjustment_amount`、`adjustment_reason`、`related_inspection_id`、`related_line_id`、`remark`。

- 数量存正值，方向由业务类型决定；金额符号由结算或冲销规则控制。
- 价格依据区分采购成交价、材料出库成本、对客收费价、历史待核对价，不能复用一个“单价”表示全部含义。
- 一般成交金额 = round(数量×单价, 2) + 经授权的调整金额；调整必填原因并留痕。历史不一致记录不能自动补成调整金额后直接过账。
- 档案名称、单位、规格及成交价格按单据快照保存，历史打印不随档案变化。

### 3.5 原材料库存与流水

`material_stock_balances`：`material_id`、`warehouse_id`、`location_id` 唯一组合；`quantity`、`inventory_value`、`valuation_status`、`version`。

`material_stock_movements`：单据及明细引用、物料、库位、业务日期、过账时间、方向、数量变化、金额变化、余额快照、成本方法/版本、操作人、冲销引用。

- 当前库存数量及金额由过账更新，不允许普通资料接口直接改。
- 历史计价未核实时 `valuation_status=pending`，未知金额不得伪装成0。
- 首期建议提供“移动加权成本”策略：入库按核实成本增加金额，领用按过账时平均成本计算；这属于新系统建议，不是从现有 Excel 得出的既定计价法。
- 成本策略由管理员选择、按生效时间版本化；已有过账数据后不能随意切换并重算历史。首期不实现任意公式或无约束的多成本引擎。
- 客户检测耗材收费走费用明细，不等同于材料出库成本；同一领用可以关联检测但不自动产生重复应收。
- 同一 SKU 的库存可以汇总，不同单位、不同物料数量不做无意义的总数量相加。

### 3.6 往来与收付款

沿用应收应付、收付款单、款项分摊模型。采购过账可形成应付，但历史 Excel 没有付款信息，导入时结算状态为“待核对”，不能假定全部欠款或已付清。

“苍南正俭编织袋”“扬州敏华粉末涂料”等可作为供应商候选；“天顺用”“淘宝试用”“新角阀”“无锡周岩红色”只保留为原摘要，经过映射后才拆出往来单位、用途或属性。

## 4. 计费规则配置模型

### 4.1 后台配置项

| 配置项 | 支持内容 |
| --- | --- |
| 费用项目 | 检测费、材料费、运输费、其他费用，可启停 |
| 适用条件 | 业务类型、客户/客户分组、气瓶类型、规格、检测结果 |
| 计费方式 | 按只、按服务次数、按材料基础单位数量、按批固定价、人工录价 |
| 价格 | 单价、固定金额；材料价可选择指定报价，不直接取采购成本 |
| 条件组合 | 首期固定字段的等值/范围及 AND 组合，不开放任意脚本 |
| 应收确认节点 | 接收确认、检测结算确认、返还确认，按业务方案选择其一 |
| 人工调整 | 是否允许、允许角色、原因必填 |
| 生效管理 | 草稿、已发布、停用；生效起止、版本号、优先级 |

### 4.2 数据实体

- `fee_items`：项目编码、名称、计费单位、启停。
- `pricing_rule_versions`：规则号、版本、适用条件、计价方式、单价/固定价、应收节点、优先级、生效区间、调整权限、发布人。
- `fee_lines`：关联气瓶/送检业务/材料领用、费用项目、命中规则版本、计费数量、单价、金额、调整原因、结算状态。

### 4.3 规则执行边界

1. 默认推荐客户专属价优先于客户分组价，再到规格通用价；同等优先级重叠规则发布时拒绝或要求修正。
2. 找不到规则时转人工录价待确认，不自动按0收费。
3. 按批收费只生成一次，不能为每只瓶重复生成；按服务次数明确绑定本次检测服务 ID。
4. 对同一服务、费用项目与来源事件建立幂等约束，应收在配置节点生成一次；返还等后续动作只引用。
5. 服务首次确认报价后冻结规则版本；过账后新版本不回写历史，差异通过费用调整单处理。
6. 首期提供业务金额，不将含税/不含税概念默认推导为税务开票结果。

## 5. 报废规则配置模型

### 5.1 后台配置项

- 规则编码、名称、适用瓶型/规格、所有权类型、生效时间与版本。
- 触发方式：人工提出，或按已维护的业务字段给出候选提醒。
- 可选条件：检测结果、复检次数、人工缺陷等级、录入的报废原因；如配置日期阈值，需明确基准日期及天/月/年单位。
- 条件关系：全部满足/任一满足，空值或缺失依据转人工处理。
- 处理动作：提醒、隔离、生成报废申请。自动规则不能直接销毁档案或完成实物处置。
- 客户确认是否必需、依据/附件是否必需、确认角色、处置方式字典、原因必填项。
- 不启用系统内置的法定周期或法定判废结论；规则依据由公司填写维护。

### 5.2 数据实体

- `scrap_rule_versions`：条件、动作、客户确认要求、证据要求、授权角色、生效区间、版本、发布人。
- `scrap_cases`：气瓶 ID、本次检测 ID、原因、规则版本、条件证据快照、状态、提出/确认人、客户确认记录、时间。
- `scrap_disposals`：报废案件、实际处置日期、方式、交接人、库位、处置单据及库存流水引用。

### 5.3 不可被普通配置绕过的约束

1. 气瓶身份唯一；报废确认、库存流水和操作记录必须可追溯。
2. 已确认报废的气瓶不得通过正常销售/返还出库；未实物移出时仍有报废在库数量。
3. 实物处置由授权人员单独确认，不能因规则自动命中就扣库存。
4. 客户所有方保持明确，规则不能把客户气瓶自动变为公司资产。
5. 配置变更不覆盖旧案件；纠错采用受控撤销，已处置不能普通编辑恢复。

可配置指业务判定条件与流程要求可维护，不意味着操作者可以关闭全部权限和追溯约束。

## 6. 历史台账导入设计

首期增加“本台账格式的导入预览与物料映射”，不扩展为任意 Excel 导入器。

1. 原文件只读保留，计算文件摘要；导入记录保存文件、工作表、行号、原值、公式和缓存值。
2. 工作表映射到物料候选；标准化括号/空格只用于匹配，保留源名称。
3. 数量/单位分拆，日期按格式及2026年上下文解析，所有推断显示在预览中。
4. 只有有效日期/摘要及实际收发信息的行才作为交易候选，跳过纯公式模板行；有摘要但无数量的行标为不完整，不直接生成单据。
5. 不从汇总页再导入一份业务，避免与明细重复；汇总仅用于对账。
6. 将字段缺失、数量金额不符、单位疑点、无日期、公式错误分别列入异常清单。
7. 以源文件摘要、工作表和源行建立重复导入保护；同源行同时有收发业务时保留子事件标识。
8. 正式启用可选择“核实后的期初余额”或“完整核实历史流水”一种路径，同一期间不能两种都计入库存。
9. 未核实的历史费用/付款不生成正式应付余额；历史原始资料可先作为只读参考保存。
10. 空白、未知、确认为0三种情况分别处理，不一律补0。

## 7. 对首期开发的直接影响

- 首页和菜单以客户气瓶检测流转、公司材料收发存为重点；自有气瓶购销按开关隐藏。
- 材料属性增加规格、颜色、型号、单位精度；采购价、出库成本、对客收费价分别建模。
- 增加规则配置菜单：费用项目、计费方案、报废规则、处置方式。
- 增加规则发布和历史快照，不做需要开发人员改代码的固定价格/报废阈值。
- 日报保持用户熟悉的“入库数量/金额、出库数量/金额、库存数量/余额”布局，但由业务流水计算。
- 验收新增：规则版本不回写旧单、同一服务不重复收费、报废不提前扣实物库存、单位混写能被识别、异常金额不自动过账。

下一步可按这些属性设计数据库迁移及页面原型。历史单位/金额存在疑点不影响模型开发，作为导入时的数据待核对事项处理。
